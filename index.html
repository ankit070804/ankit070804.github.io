Projects

Assistive communication framework↗

Converts eye blinks into Morse code so people who cannot speak or type can still communicate. Adds Sign Language Grammar, Trie-based word prediction and a Digital Twin for logging. I compared fine-tuned Transformer models and chose Flan-T5-small for the best quality and latency trade-off. It cuts blinks by 26.7% on average, up to 44.9% for long sentences.

  • PyTorch
  • OpenCV
  • MediaPipe
  • Transformers

UAV localization error prediction↗

Predicts how far off a drone's visual localization will be, frame by frame, from image, depth, segmentation and pose data (TartanAir). Each prediction is explained with SHAP, and a local LLM writes a plain-language report. Tested by holding out whole flight sequences: R² of about 0.79 on unseen routes, versus 0.92 on a random split that leaks nearby frames.

  • Scikit-learn
  • SHAP
  • OpenCV
  • Ollama

ModelGuardian: ML drift monitoring↗Team project

Built in 6 hours at the myonsite Ascend hackathon. Watches a deployed fraud-detection model, detects drift with Kolmogorov-Smirnov and KL divergence written from scratch (no drift libraries), and triggers an automated rollback through GitHub Actions. Includes a live dashboard and a traffic generator for normal, drifted and adversarial inputs.

  • FastAPI
  • TypeScript
  • Next.js
  • GitHub Actions

Explainable deepfake detection↗

Classifies a face image as real or fake, then uses Grad-CAM to highlight the regions that drove the decision, so the prediction can be checked instead of trusted blindly.

  • PyTorch
  • EfficientNet-B0
  • Grad-CAM
  • Streamlit

Fake news propagation system↗

TF-IDF and Random Forest classifier trained on 800+ PolitiFact articles, with 77% accuracy and a 0.77 F1-score. Runs in Streamlit with live probability scores and simulates how a story spreads using the SIR model.
